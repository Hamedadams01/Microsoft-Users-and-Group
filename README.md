# Creating Users and Groups in Microsoft Entra

Overview

In this home lab, I demonstrate how to create and manage users and groups within **Microsoft Entra Admin Center**, which is the cloud-based version of Active Directory. This lab simulates a real-world IT environment where administrators manage identities, assign access, and organize users into groups for better control and security.

---

## **Objectives**

- Create and configure a new user account
- Understand cloud-based identity management
- Create a security group for organizational structure
- Add users to groups for access control and management
